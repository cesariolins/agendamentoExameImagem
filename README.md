# Agendamento de Exames de Imagem

Aplicação full stack para agendamento de exames de imagem: o paciente busca um exame, escolhe um médico, vê os horários livres de uma data e agenda.

- **Back-end:** NestJS 12 + Prisma 7 + SQLite (`backend/`)
- **Front-end:** React 19 + Vite 8 + Tailwind CSS 4 (`frontend/`)

> 🚧 Em construção. As instruções completas de execução, as decisões de arquitetura, as premissas e os exemplos de requisição entram ao final do desenvolvimento.
> Arquitetura e convenções: veja o [AGENTS.md](./AGENTS.md).

## Rodando (prévia)

Requisito: Node.js ≥ 22.12.

```bash
npm install
npm run dev
```
